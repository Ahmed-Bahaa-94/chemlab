# مختبر الكيمياء التفاعلي والجدول الدوري (ChemLab & Interactive Periodic Table)

تطبيق ويب تعليمي وتفاعلي متقدم لمادة العلوم والكيمياء يدعم **اللغتين العربية والإنجليزية** مع إمكانية التبديل بين **الوضع الليلي والوضع المضيء (Dark & Light Themes)**.

---

## 🌟 مميزات التطبيق

### 1. دعم ثنائي اللغة (عربي / English) ومحاذاة كاملة (RTL / LTR)
- زر تبديل اللغة بضغطة واحدة من الشريط العلوي `🌐 English / العربية`.
- ترجمة متكاملة لجميع أسماء العناصر، الفئات، الأدوات، شروحات التفاعلات، المعمل، ونوافذ التفاصيل، وأسئلة الاختبار.

### 2. التبديل بين الوضع الليلي والوضع المضيء (Dark / Light Modes)
- زر `🌙 داكن` / `☀️ مضيء` لتغيير المظهر بالكامل بما يناسب بيئة القراءة والإضاءة.
- حفظ التفضيلات تلقائياً في المتصفح (`localStorage`).

### 3. الجدول الدوري التفاعلي (118 عنصراً)
- شبكة قياسية وفق معايير IUPAC العالمية (18 عمود × 7 صفوف + اللانثانيدات والأكتينيدات).
- تمييز لوني دقيق لكل الفئات الكيميائية.
- بحث فوري بالاسم، الرمز، أو العدد الذري.
- **شريط محاكاة درجات الحرارة (0K إلى 6000K):** لمراقبة تغير حالات المادة (صلب/سائل/غاز) في الوقت الفعلي.

### 4. محاكي نموذج بور الذري وبطاقة العنصر (Animated Bohr Atom Visualizer)
- رسم النواة المركزية ومدارات الإلكترونات المتحركة ($K, L, M, N, O, P, Q$).
- تفاصيل التوزيع الإلكتروني، التكافؤ، الكهروسالبية، والاستخدامات الواقعية.
- زر نقل مباشر للعنصر إلى المعمل الافتراضي.

### 5. معمل دمج العناصر الافتراضي ومجسم الجزيء 3D (Reaction Lab & 3D Molecule)
- منصة تفاعل ذكية تدعم السحب والإفلات وتحديد كميات الذرات ($2H + O$).
- **عند نجاح التفاعل:** مؤثرات بصرية متوهجة وشرر ودخان، مع **مجسم جزيئي ثلاثي الأبعاد تفاعلي (3D Ball-and-Stick)** يمكن تدويره بزاوية 360°.
- **عند عدم التفاعل:** تفسير علمي ذكي يوضح السبب للطلاب.
- كتالوج الوصفات الكيميائية المكتشفة.

### 6. مؤثرات صوتية تفاعلية (Web Audio API)
- مؤثرات صوتية مدمجة وخفيفة (نقر، فقاعات، فوران، ونغمات النجاح).
